# 前端设计规范

> 唯一权威源。任何前端视觉与布局决策以本文为准；实现位于 frontend/src/styles/ 与 frontend/src/components/。
> 本文不定义路由、API 字段或业务状态机；业务契约仍以 docs/plans/single-task/00-总览与契约.md 为准。

## 1. 适用范围与强制力

| 触发改动 | 开工前动作 | 验收动作 |
|---|---|---|
| 新增页面或路由视图 | 阅读本文全部章节与页面契约 | 两主题、断点、键盘、空/载/错状态 |
| 调整区域布局或页面顺序 | 阅读 §7 | 核对布局地图与伸缩规则 |
| 新增或修改组件 | 阅读 §5、§6、§8、§9 | 复用 token；覆盖全部状态 |
| 改颜色、透明度、阴影 | 阅读 §3 | 计算对比度并记录实际值 |
| 改字号、字重、行高 | 阅读 §4 | 检查中文、长文本与数字 |
| 改间距、圆角、控件尺寸 | 阅读 §5 | 检查 4px 网格与连续曲率 |
| 改过渡、动画、滚动效果 | 阅读 §6 | 验证临界阻尼及减少动效 |
| 改主题初始化或持久化 | 阅读 §3.1、§7.2 | 验证首屏、系统跟随、刷新保持 |
| 改前端交互文案或状态含义 | 阅读 §3.4、§8 | 不得混淆 warning/danger/info/success |

| 关系 | 规则 |
|---|---|
| 与 docs/AGENTS.md | AGENTS 负责协作流程；本文负责设计；设计决策冲突时以本文为准 |
| 与业务契约 | 业务字段、阶段名、状态枚举冲突时以业务契约为准，并修订本文映射 |
| 修改本文 | 同步检查 AGENTS 中强制阅读链接，追加 §11 变更记录 |
| 临时例外 | 禁止静默例外；必须写变更记录、影响面和回退方式 |
| 证据 | 涉及视觉的改动必须保留浅色/深色实际渲染证据 |

## 2. 设计原则

1. 信息先于装饰：阅读任务、状态和产物是首层内容。
2. 语义唯一：同一状态在两主题、各页面使用同一语义色。
3. 层级靠背景与边框：阴影只辅助悬浮，不承担分区职责。
4. 控件默认可预测：相同操作具备相同尺寸、反馈和键盘行为。
5. 动效只解释变化：临界阻尼，无回弹，不阻碍连续操作。
6. 扩展靠 token：新页面组合既有规则，不建立局部视觉方言。

## 3. 色彩系统

### 3.1 主题与使用约束

| 项 | 强制规则 |
|---|---|
| 主题属性 | html data-theme="light" 或 "dark" |
| 默认主题 | 无 ty-theme 时跟随 prefers-color-scheme |
| 用户主题 | 手动切换写 localStorage["ty-theme"]，仅 light/dark |
| 首屏 | 在 CSS 前同步设置 data-theme；禁止等待 Vue 挂载 |
| 系统变化 | 未手动选择时跟随；手动选择后不被系统变化覆盖 |
| 颜色来源 | 颜色必须引用语义 token；禁止在视图写十六进制颜色 |
| 透明度 | 仅 overlay、表格斑马纹、禁用态和描边可用透明度 |
| 原生控件 | 同步 color-scheme，保证滚动条、选择器和表单控件一致 |

## 4. 字号与排版系统

### 4.1 唯一字号阶

| token | px | 行高 | 字重 | 用途 | 单区域出现位置上限 |
|---|---:|---:|---|---|---:|
| text-display | 24 | 1.4 | 700 | 页面标题、关键总进度 | 1 |
| text-title | 20 | 1.4 | 650–700 | 弹层标题、详情大数值 | 1 |
| text-section | 16 | 1.4 | 600–650 | 卡片/区块标题 | 每区块 1 |
| text-body | 14 | 1.7 | 400–600 | 正文、表格、按钮、输入值 | 不限制 |
| text-caption | 12 | 1.6 | 400–600 | 标签、辅助说明、徽标、等宽标识 | 每组不超过 2 行 |
| 等宽正文 | 12 | 1.8 | 400 | 代码、预格式块、ID、sha | 不限制 |

| 内容类型 | 必须使用 | 判定规则 |
|---|---|---|
| 页面标题 | text-display | 每页仅一个 h1 |
| 弹层标题 | text-title | 仅独立浮层 |
| 区块标题 | text-section | 卡片内功能分区 |
| 正文/表格/表单值 | text-body | 用户必须连续阅读或编辑 |
| 表单标签 | text-caption 600 | 与字段成对，不作为正文 |
| 辅助说明 | text-caption secondary | 补充规则，不承载唯一关键操作 |
| 徽标/状态 | text-caption 600 | 不超过一行 |
| 代码/ID/JSON | 等宽正文 | 保留字符边界与换行 |
| 数字 | text-body + tabular-nums | 进度、成本、时间、数量、版本 |
| 关键数字 | text-display/title + 等宽数字 | 仅概览指标 |

### 4.2 排版硬约束

| 项 | 规则 |
|---|---|
| 全站字号 | 仅 12/14/16/20/24px 五阶；禁止新增字号 |
| 正文下限 | 禁止 13px 以下正文；12px 仅用于辅助、标签、代码 |
| 中文行高 | 正文 ≥1.7；标题 ≥1.4；代码 ≥1.8 |
| 字体 | 中文使用系统无衬线；不引入网络字体 |
| 等宽 | ID、代码、sha、模型名使用等宽字体 |
| 数字对齐 | 表格数字、成本、时间启用 tabular-nums |
| 长文本 | 文件名、URL、错误信息允许断行；不得撑破卡片 |
| 截断 | 仅列表 ID 可单行省略；完整值须可通过详情或 title 获取 |
| 字重 | 400 正文、500 导航、600 标签/控件、650–700 标题 |
| 对齐 | 表单标签左对齐；数值右/左保持一致；不居中排正文 |

## 5. 间距、圆角、连续曲率与阴影

### 5.1 间距阶

| token | px | 典型位置 |
|---|---:|---|
| space-1 | 4 | 图标与极短文本、紧密状态 |
| space-2 | 8 | 按钮组、标签、控件内部间隔 |
| space-3 | 12 | 字段内部、导航项、紧凑卡片 |
| space-4 | 16 | 卡片之间、表单网格 |
| space-5 | 20 | 卡片头部、次级分区 |
| space-6 | 24 | 卡片内边距、区块内部 |
| space-8 | 32 | 页头下、登录卡片 |
| space-10 | 40 | 内容区顶部、侧栏分区 |
| space-12 | 48 | 空态、页面大区间 |

| 约束 | 规则 |
|---|---|
| 网格 | 所有外间距和固定尺寸使用 4 的倍数 |
| 例外 | 1px/2px 边框、6px 状态点、18px 图标允许 |
| 视图局部 | 可定义布局尺寸；不得复制全局组件样式 |
| 触控 | 可点击区域 ≥32px；主输入高 40px |

### 5.2 圆角 token 与连续曲率

| token | px | 用途 |
|---|---:|---|
| radius-sm | 6 | 文件选择按钮、小型内嵌控件 |
| radius-md | 10 | 按钮、输入框、导航项、选项 |
| radius-lg | 14 | 卡片、表格容器 |
| radius-xl | 20 | 大型浮层 |
| radius-pill | 999 | 标签、进度槽、胶囊开关 |

| 元素 | 连续曲率要求 | 圆角 token |
|---|---|---|
| 按钮 | 必须 squircle | md/sm |
| 标签/状态徽标 | 必须 squircle | pill |
| 输入框/选择器/文本域 | 必须 squircle | md |
| 卡片/浮层/表格容器 | 必须 squircle | lg/xl |
| 头像/品牌块 | 必须 squircle | md 或 12px |
| 开关/进度槽 | 必须 squircle | pill |
| 状态点 | 允许正圆 | 50% |

| 实现项 | 规则 |
|---|---|
| 标准写法 | 同时声明 corner-shape: squircle 与 border-radius |
| 属性顺序 | border-radius 提供基础形状，corner-shape 调整角曲率 |
| 支持度 | 作为渐进增强；不支持浏览器忽略 corner-shape |
| 降级 | 回退正圆角，尺寸、边框、排版、功能不得变化 |
| 观感差异 | 降级后角部略机械；不得用 SVG 或图片模拟 |
| 禁止 | 禁止只用 border-radius 冒充已实现连续曲率 |
| 禁止 | 禁止为胶囊控件使用随宽度变化的视觉圆角 |

### 5.3 阴影

| 层级 | 规则 |
|---|---|
| canvas/surface | 默认无阴影，以背景与 border 分层 |
| raised | 浅色 0 1px 2px 4% + 0 8px 24px 5% |
| 深色 raised | 仅 0 1px 2px 12%；主要靠 border |
| 悬停 | 不通过放大阴影表达可点击 |
| 文字 | 禁止文字阴影 |
| 内阴影 | 禁止用于输入框 |

## 6. 动效系统

### 6.1 唯一物理模型

| 参数 | 固定规则 |
|---|---|
| 类型 | 所有过渡与入场使用弹簧模型 |
| 阻尼比 | ζ=1，临界阻尼 |
| 过冲 | 不允许；位移、缩放、透明度不得越过终值 |
| 曲线 | 仅使用本文三档 linear() 采样串 |
| 替代曲线 | 禁止 ease、ease-in-out、cubic-bezier、spring 回弹 |
| 属性 | 优先 transform/opacity；颜色与边框可过渡 |
| 布局动画 | 不动画 width/height，进度条 width 除外 |
| 中断 | 新交互从当前值接续，不强制播放完整周期 |

### 6.2 三档预设

| token | stiffness | mass | ζ | 时长 | 用途 |
|---|---:|---:|---:|---:|---|
| spring-fast | 1600 | 1 | 1 | 231ms | hover、按下、焦点颜色 |
| spring-standard | 900 | 1 | 1 | 308ms | 展开、进度更新、局部面板 |
| spring-slow | 400 | 1 | 1 | 462ms | 页面/卡片入场、toast |

> 时长为弹簧响应距终值不超过 0.001 的采样边界；三条曲线归一化后相同，时长不同。
