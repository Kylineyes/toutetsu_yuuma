# AGENTS.md

本仓库协作与提交规范，适用于所有代理及子代理。

前端视觉与布局的唯一权威规范：[前端设计规范](design/前端设计规范.md)；相关改动必须遵守第 13 条。

1. 编写代码时，注释、说明性文字、界面文案、日志、错误提示及项目文档统一使用简体中文。
2. Git 提交说明、合并说明及开发结果描述使用简体中文。
3. 提交遵循 Conventional Commits：`<type>(<scope>): <简体中文描述>`；无需范围时可省略 `(<scope>)`。
4. 每项开发工作必须在对应的独立分支进行，不直接在 dev 或 main 上开发。
5. 优先从最新 dev 建立工作分支，例如 feat/command-menu、fix/pcb-loader、chore/qt6-environment。
6. 工作完成并验证后，将工作分支合并到 dev，然后推送 dev 到远端；保留有意义的合并记录，合并提交说明也使用简体中文约定式提交。
7. dev 合并到 main 由用户执行。代理不得自行合并、提交或推送 main，不得强制推送或跳过提交钩子。
8. 如果 dev 尚不存在，先从远端 main 建立 dev，再按上述流程开展工作。
9. 推送失败、测试失败、未完成的功能必须如实说明，不得把未验证内容当作完成。
10. 修改后运行相应构建及测试；涉及 WebUI 的变更要实际启动应用并交互验证，不能只凭编译通过判断成功。
11. 所有子代理启动时与主代理的模型/思考强度一致，并核对实际会话模型记录和工具执行结果。
12. 启动时明确模型、任务范围、独立分支和证据路径；模型不可用时如实报告，不擅自替换。
13. 任何涉及前端布局、视觉、字号、配色或动效的改动，必须先阅读并遵守 [前端设计规范](design/前端设计规范.md)；修改设计决策必须同步更新该文档的变更记录，并检查本引用。
